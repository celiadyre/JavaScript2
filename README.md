A social media SPA built with HTML, CSS and JavaScript using the Noroff API.

Built With

- HTML
- CSS3
- JavaScript

Features

- User registration
- User login
- Authentication
- Social media feed
- View individual posts
- Create posts
- Edit your own posts
- Delete your own posts
- Add comments
- Like posts
- View profiles
- Follow and unfollow users
- Search posts
- Filter broken post images

This application requires login credentials for the Noroff API. You can register an account using a Noroff e-mail address on the registration page.
